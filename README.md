**Stack**

`React` `Vite` `Node.js` `Express.js` `MongoDB` `Mongoose` `JWT` `Cloudinary`

### 02 · TechCodeClaw

**An AI-powered coding assistant CLI and Telegram bot for interacting with and modifying codebases.**

TechCodeClaw goes beyond a simple chatbot by combining AI interaction with **codebase operations, planning, web research and an approval-based workflow for file changes**.

**Highlights**

- 🤖 AI Agent Mode for codebase operations
- 💬 Ask Mode for codebase questions and research
- 🧭 Plan Mode for structured task execution
- 📱 Telegram bot integration
- 🛡️ Approval workflow before applying file mutations
- 🔎 Web research capabilities
- 📂 File creation, modification and deletion workflows
- 🔐 Protection against unsafe paths and sensitive files

**Stack**

`TypeScript` `Bun` `OpenRouter` `AI SDK` `Firecrawl` `Commander` `Telegraf`
